# fleet-inventory-analysis-excel
Inventory analysis and reporting for Montgomery fleet — Excel-based analysis

## 📌 Project Overview
This project contains the fleet equipment inventory data and analysis performed for Montgomery (Parts 1 & 2). The work focuses on inventory categorization, utilization tracking, and data quality checks in Excel.

## 🧰 Tools Used
- Microsoft Excel (Pivot Tables, Filters, Formulas)
- Basic data validation and cleaning techniques
- Screenshots of charts for visualization

## 📁 Repository Contents
- `Montgomery_Fleet_Part1.xlsx` — Original / cleaned dataset (part 1)
- `Montgomery_Fleet_Part2.xlsx` — Original / cleaned dataset (part 2)
- `screenshots/` — Optional images of key charts or dashboard elements
- `README.md` — This file

## 🎯 Objectives
- Consolidate and validate fleet inventory data from two sources
- Identify duplicates, missing values, and inconsistent entries
- Produce summary metrics and pivot tables for:
  - Inventory counts by category
  - Equipment status / utilization
  - Age / condition analysis
